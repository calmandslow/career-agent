# Career Agent V1.6.2

V1.6.2 closes the issues found in the first real V1.6.1 acceptance run.

## Changes

- Adds a shared conservative rewrite policy for Resume Tailor and the semantic verifier.
- Treats verifier suggestions as feedback rather than automatically trusted final copy.
- Deterministically downgrades known unsafe personal-project wording before the second review.
- Keeps rewritten resume claims and `claim_audit` synchronized.
- Preserves `started_at` when a run pauses for human review.
- Adds `qwen_resolve_human_review.py` to approve, conservatively normalize, or commit edited pending output without another API call.
- Removes `pending_human_review.json` after successful human approval.
- Updates run-report and API versions to `1.6.2`.
