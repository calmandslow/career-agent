# V2.0 对话验收材料

先使用 `../v19` 中的简历和 JD 创建一个“目标公司 / 增长产品经理”岗位，并关联材料。

依次在 Career Agent 输入框发送：

1. `我通过了一面，下周三参加业务二面。一面主要问增长项目，面试官觉得我的数据归因和个人贡献讲得不够清楚，帮我准备。`
   - 预期：显示招聘进展提案；确认前岗位不变化，确认后生成一面和二面状态及风险。
2. `开始数据归因专项训练`
   - 预期：进入教练模式，检索相关证据并提出第一道专项问题。
3. `我负责实验设计，因为两个组都参加活动，所以用用户 ID 随机分流，对照比较了 12 万用户两周数据。`
   - 预期：即时反馈并继续追问，不创建正式模拟面试会话。
4. `结束训练`
   - 预期：先展示训练结果写回提案；确认后准备度显示最近训练。
5. `补充证据：我按注册 30 天划分新老用户，新用户次周留存提升 3.2 个百分点。`
   - 预期：确认后写入职业证据库，并关联当前岗位。
6. `按照真实面试开始完整模拟`
   - 预期：没有问题清单时先提议生成；已有问题清单时创建正式模拟并进入“模拟面试”页。
7. `什么是机会成本？`
   - 预期：进入普通对话模式，明确不修改职业档案。

取消任一提案后，岗位状态、证据和训练结果都不应改变。
