# Career Agent V1.7.1.1

This patch improves Answer Coach quality and reduces validation-repair cost.

## Changes

- Rejects unsupported adaptation or delivery promises such as “两周内适应”
  unless the same duration is present in candidate evidence.
- Requires hypothetical product scenarios to start with business/user discovery
  and constraints before proposing an Agent or feature.
- Requires operational ABTest coverage: randomization/exposure, core and
  guardrail metrics, SRM/contamination, duration/stopping rules, confidence and
  practical significance.
- Associates validation defects with the exact answer index and defect code.
- Repairs only the failed `PreparedAnswer`; all other answers and profile fields
  are retained unchanged.
- Sends only evidence already cited by the failed answer into the repair call,
  reducing repeated input tokens.

## Validation

- 54 unit/integration tests pass.
- Python bytecode compilation passes.
- The complete Mock preparation and review workflow passes.
- A dedicated integration test confirms that a two-answer batch makes one
  single-answer repair and preserves the unaffected answer exactly.
